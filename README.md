# ÉTS+

[English](README.en.md)

Ton horaire, tes notes, tes courriels de l'ÉTS et le transport, dans une seule app Android.

Pas de compte à créer, pas de serveur entre toi et l'école : tu te connectes avec ton compte ÉTS et c'est tout.

Fait par [Studio Synocti](https://synocti.ca). Pas une app officielle de l'ÉTS.

## Compiler

```
./gradlew assembleGithubRelease
```
